# Aperture `v0.4.0` — Phase 3 personal library

Watchlist, favorites, custom lists with reorder, and diary / `watch_entries` on
the public URL (after a possible API cold start). Auth required for mutations;
public custom lists are readable by id when logged out.

## Live URLs

| Surface | URL |
|---|---|
| Web (Vercel) | https://aperture-sepia.vercel.app |
| API (Render Free) | https://aperture-api-da3c.onrender.com |
| API via BFF | https://aperture-sepia.vercel.app/api/proxy/health/ready |

## What’s included

- **P3.1 Watchlist** — unique system list per user; `/api/v1/me/watchlist*`; detail toggle; `/library/watchlist`
- **P3.2 Favorites** — unique system list; `/api/v1/me/favorites*`; detail toggle; `/library/favorites`
- **P3.3 Custom lists + reorder** — CRUD under `/api/v1/me/lists` and `/api/v1/lists/{id}`; dense renumber reorder (`item_ids[]`); visibility `private` / `public` / `unlisted`; move up/down UI; `/library/lists`, `/lists/[id]`; Add to list on detail
- **P3.4 Diary** — `watch_entries` in `backend/app/library/`; `/api/v1/me/watch-entries`; rewatches; optional `remove_from_watchlist`; `/library/diary`; Log watch on detail
- Content refs shared via `app.common.content_refs` (`movie` / `tv`, alias `tv_show`)
- ADR: [ADR-0008](../decisions/ADR-0008-personal-library-lists.md)

## Known free-tier tradeoffs

- Render Free API may sleep after ~15 minutes idle (~1 minute wake + migrate-on-start).
- Supabase Free may pause after ~1 week of low activity.
- No managed database backups on the free tier — optional manual `pg_dump`.
- Custom-list discovery / trending, episode-level diary, Letterboxd import, and collaborative lists remain later phases.
- Auth write rate limits remain shared CacheBackend buckets (lists + diary); Redis degrade falls back to process-local counters.
