# Aperture `v0.3.0` — Phase 2 metadata

Canonical catalog, detail pages, PostgreSQL full-text search, and Redis-backed
cache / search rate limits on the public URL (after a possible API cold start).

## Live URLs

| Surface | URL |
|---|---|
| Web (Vercel) | https://aperture-sepia.vercel.app |

## What’s included

- **P2.1 Canonical catalog** — `content_items` / `external_ids` (ADR-0004), people/seasons/episodes/credits, fixture + TMDb-ready ingest, seed set in production
- **P2.2 Detail UX** — public `GET /api/v1/movies|tv|people/{id}`; RSC pages `/movies|tv|people/[id]` with TMDb image CDN
- **P2.3 Search v1** — PG FTS across movies / TV / people; `GET /api/v1/search`; header search → `/search?q=…`
- **P2.4 Redis** — Upstash/Compose Redis via `REDIS_URL`; metadata detail cache (`X-Cache: HIT|MISS`); atomic search IP rate limits with process-local fallback; multi-instance notes + `watch_entries` P3 design notes
- ADRs: [ADR-0004](../decisions/ADR-0004-content-identity.md), [ADR-0006](../decisions/ADR-0006-redis-search-staging.md); auth RL → Redis deferred to **P11** ([ADR-0005](../decisions/ADR-0005-auth.md)); ops: [redis-and-multi-instance](../ops/redis-and-multi-instance.md)

## Verified on production (2026-08-01)

- API `/health/ready` → ready (direct + BFF proxy)
- `GET /api/v1/search?q=Inception` → movie hit; BFF `/api/proxy/api/v1/search?q=Morgan` → person hit
- Detail cache: first `GET /api/v1/movies/{id}` → `X-Cache: MISS`, second → `HIT`
- Pages `200`: `/`, `/search?q=Inception`, `/movies/{id}`, `/tv/{id}`, `/people/{id}`
- Invalid search `types` → `400` (FTS path live)

## Ops checklist

- Render env **`REDIS_URL`** = Upstash **TCP** URL (`rediss://…`), not REST — required for shared search RL / cache across instances ([ops doc](../ops/redis-and-multi-instance.md)).
- FTS migration `f6a7b8c9d0e1` applies via migrate-on-start when the API wakes.

## Known free-tier tradeoffs

- Render Free API may sleep after ~15 minutes idle (~1 minute wake + migrate-on-start).
- Supabase Free may pause after ~1 week of low activity.
- No managed database backups on the free tier — optional manual `pg_dump`.
- Auth login/register/refresh rate limits remain Postgres until P11; search RL uses Redis in P2.4.
- OpenSearch, live TMDb-on-search-miss, and personal library (`watch_entries`) remain later phases.
