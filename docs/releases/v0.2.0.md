# Aperture `v0.2.0` — Phase 1 user platform

Password auth, hardening, Google OAuth, and profile settings on the public URL
(after a possible API cold start).

## Live URLs

| Surface | URL |
|---|---|
| Web (Vercel) | https://aperture-sepia.vercel.app |
| API (Render Free) | https://aperture-api-da3c.onrender.com |
| API via BFF | https://aperture-sepia.vercel.app/api/proxy/health/ready |

## What’s included

- **P1.1 Password auth** — register (email + username + password), login (email or username), logout, refresh via same-origin BFF cookies (`ap_*` local / `__Host-ap_*` prod)
- **P1.2 Hardening** — DB-backed rate limits, enumeration-safe login, refresh reuse grace + family revoke, trusted BFF client IP
- **P1.3 Google OAuth** — BFF-owned PKCE flow, JWKS-verified `id_token`, no email auto-link; explicit Link Google on Account; Google-only users seed username/display name
- **P1.4 Profiles** — `GET/PATCH /api/v1/users/me` (+ preferences), public `GET /api/v1/users/{username}`, `/settings` UI, `/u/[username]`, initials avatar, theme/spoilers/language prefs, 30-day username rename cooldown
- Auth ADR: [ADR-0005](../decisions/ADR-0005-auth.md); hosting remains [ADR-0003](../decisions/ADR-0003-hosting-and-bff.md)

## Verified on production (2026-08-01)

- API `/health/ready` → ready
- BFF register → `/api/auth/me` → atomic profile + preferences PATCH → public profile JSON
- Pages `200`: `/`, `/login`, `/signup`, `/account`, `/settings`, `/u/{username}`
- Google start → `307` to Google OAuth (PKCE + prod redirect URI)

## Known free-tier tradeoffs

- Render Free API may sleep after ~15 minutes idle (~1 minute wake + migrate-on-start).
- Supabase Free may pause after ~1 week of low activity.
- No managed database backups on the free tier — optional manual `pg_dump`.
- Avatar upload, email verification, password reset, unfollow/unlink Google, and genre onboarding remain deferred.
