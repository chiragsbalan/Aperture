# Design System

## Purpose

This directory documents Aperture's visual language.

It defines reusable UI patterns and interaction principles, not individual pages.

## Philosophy

The Design System should emerge naturally as the frontend matures.

Only document stable, reusable patterns.

## Potential Documents

- Colors
- Typography
- Spacing
- Layout
- Buttons
- Forms
- Cards
- Icons
- Animations
- Accessibility

## Do Not Document

- Individual pages
- Temporary experiments
- Backend behavior
- API contracts
- Feature specifications

## AI Agent Instructions

Before creating a new document, ask:

- Is this reused across multiple parts of the application?
- Has the design stabilized?
- Will documenting it improve consistency?

If yes, create a dedicated document.

Otherwise, wait until the pattern matures.

The Design System should describe Aperture's visual language—not implementation details.
